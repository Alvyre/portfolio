# Fichiers de DOOM (shareware)

Le code Konami ouvre DOOM (épisode 1, niveau 1) dans une popin. Le jeu utilise ces deux fichiers de la version shareware 1.9 :

| Fichier | Taille | MD5 |
|---|---|---|
| `DOOM.EXE` | 709 753 octets | `42239c45d3a5e19fab6962f7446c6e13` |
| `DOOM1.WAD` | 4 196 020 octets | `f0cefca49926d00903cf57551d901abe` |

Provenance : dépôt [nneonneo/universal-doom](https://github.com/nneonneo/universal-doom). `DOOM.EXE` correspond à son fichier `DOOMD.EXE`, le DOOM d'origine pour DOS, sans la partie Windows du `DOOM.EXE` de ce dépôt. `DOOM1.WAD` est le WAD shareware officiel.

Ces fichiers appartiennent à id Software. La licence shareware autorise leur diffusion gratuite, sans modification.
